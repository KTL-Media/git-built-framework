Mission 1: The First Transmission

MONDAY | 🤖 SOLO MEMUBOT | ⭐
OBJECTIVE

Establish your daily automation rhythm

TOOLS: MemuBot only
ACTIONS
  1. Open MemuBot dashboard
  2. Create a "Daily Creator Pulse" automation:
    • Morning check-in message (9am)
    • Midday progress prompt (2pm)
    • Evening reflection (9pm)
  3. Customize the messages with your personal goals
  4. Activate and test the automation
DELIVERABLE
Screenshot of your automation running + first check-in response
✓ Success Indicator: You receive all 3 automated messages on Day 1
Bonus Challenge: Add a 4th automation for content idea generation
TIME: 20 MIN | XP: +100

Mission 2: The Intelligence Test

TUESDAY | 🧠 CLAUDE SKILLS | ⭐
OBJECTIVE

Learn how to structure high-quality prompts with Claude

TOOLS: Claude 101 or Claude Skills
ACTIONS
  1. Open Claude Skills
  2. Run this prompt: "I'm building [describe your business idea or project]. Help me break this down into 5 actionable steps I can complete this week."
  3. Analyze the response quality
  4. Refine your prompt and run it again with more context
  5. Save the best version to a document titled "My First Claude Pattern"
DELIVERABLE
Your refined prompt + Claude's response saved as a Pattern
✓ Success Indicator: You can clearly see the difference between your first and refined prompt
Bonus Challenge: Create 3 different prompt variations for the same goal
TIME: 25 MIN | XP: +100

Mission 3: The Synthesis

WEDNESDAY | 🔗 INTEGRATION | ⭐⭐
OBJECTIVE

Make your tools work together

TOOLS: MemuBot + Claude Skills
ACTIONS
  1. Ask Claude Skills to write you 3 daily automation message templates for MemuBot
  2. Copy Claude's output
  3. Go to MemuBot and create new automations using Claude's templates
  4. Customize the tone to match your voice
  5. Activate all 3 automations
DELIVERABLE
Screenshot showing MemuBot running Claude-generated messages
✓ Success Indicator: You receive a MemuBot message that was originally written by Claude
Bonus Challenge: Ask Claude to improve one of your existing MemuBot messages
TIME: 30 MIN | XP: +150

Mission 4: The Pattern Forge

THURSDAY | 📚 PATTERN LIBRARY | ⭐⭐
OBJECTIVE

Create and share your first reusable pattern

TOOLS: MemuBot, Claude, Pattern Library
ACTIONS
  1. Review what you've built so far (automations, prompts)
  2. Choose your best prompt or automation workflow
  3. Document it in this format: Pattern Name, What It Does, Tools Needed, Step-by-Step Setup, Example Output
  4. Upload to Pattern Library (or share in Discord #pattern-library channel)
  5. Tag it with relevant keywords
DELIVERABLE
Your first Pattern Library contribution (public or submitted)
✓ Success Indicator: Another student can replicate your pattern from your instructions
Bonus Challenge: Try someone else's pattern and give them feedback
TIME: 35 MIN | XP: +200

Mission 5: The Cowork Protocol

FRIDAY | 👥 COLLABORATION | ⭐⭐
OBJECTIVE

Use Claude Cowork for team-based thinking

TOOLS: Claude Cowork
ACTIONS
  1. Open Claude Cowork and start a new project workspace
  2. Use prompt: "I'm working on [your project]. Let's brainstorm 10 different angles or approaches I haven't considered yet..."
  3. Have a back-and-forth conversation (at least 5 exchanges)
  4. Document the best 3 ideas that emerged
DELIVERABLE
Conversation transcript or summary of your top 3 insights
✓ Success Indicator: You discovered an approach you wouldn't have thought of alone
Bonus Challenge: Invite another student to co-work with you in Discord while both using Claude Cowork
TIME: 40 MIN | XP: +150

Mission 6: The Code Forge

SATURDAY | 💻 SHIP FUNCTIONAL | ⭐⭐⭐
OBJECTIVE

Use Claude Code to build a simple tool or script

TOOLS: Claude Code
ACTIONS
  1. Open Claude Code
  2. Choose a micro-project (e.g., Simple Python automation script, HTML landing page, Social caption generator)
  3. Describe what you want to build to Claude Code
  4. Let it generate the code. Test and refine until it works.
  5. Save the code + document how to use it
DELIVERABLE
Working code + brief usage instructions
✓ Success Indicator: The code runs without errors and solves your problem
Bonus Challenge: Share your code in #builder-showcase channel
TIME: 60 MIN | XP: +250

Mission 7: The Compound Build

SUNDAY | 🏗️ FULL STACK | ⭐⭐⭐
OBJECTIVE

Combine all tools in one workflow to create something real

TOOLS: Full Stack (MemuBot + Claude Ecosystem + Pattern Library)
ACTIONS
  1. Define a mini-project: "I will create [specific deliverable] by end of day"
  2. Plan your workflow:
    • Use Claude Cowork to brainstorm
    • Use Claude Skills for content
    • Use Claude Code for tech components
    • Use MemuBot for automation
  3. Execute the build and save the process as a Pattern
  4. Ship it (share in Discord or save to workspace)
DELIVERABLE
Your completed mini-project + process documentation
✓ Success Indicator: You used at least 3 different tools in your workflow and shipped a real asset
Bonus Challenge: Record a 2-minute video walkthrough of your project
TIME: 90+ MIN | XP: +500
