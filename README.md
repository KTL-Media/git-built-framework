## The series loop

```
concept → carousel (10 slides) → clips (per slide) → reel → lead magnet → PLAYBOOK keyword → DM → lead
```

1. **Concept** — one idea, built on the playbook pattern (process interview → toolbox → proof checklist).
2. **Carousel** — 10 slides, 1080×1350, final slide always carries the CTA: *"Comment PLAYBOOK and I'll send you the free starter kit."*
3. **Clips** — one short clip per slide for Reels/TikTok/Shorts.
4. **Reel** — the full carousel animated into one video.
5. **Lead magnet** — the free starter kit PDF, delivered via the PLAYBOOK comment-to-DM flow (see the `lead-capture` playbook in `ktl-content-engine`).
6. **Nothing posts without approval** — every asset ships only after explicit sign-off on the exact content.
